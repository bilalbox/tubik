- **Gate Compose/Roborazzi in `QualityKitAndroidPlugin.kt`**: deferred because `quality-kit` owns the plugin and local edits create upgrade drift for minimal cost.
- **Defer `onConfigure` ONNX model load**: deferred because `OrtSpeechRuntime.warmup` already runs in the background and brief blocking preserves fail-closed semantics.

- **Wall-clock waits in `MusicRemovalAudioProcessorTest` / `PoTokenGeneratorTest` & deprecated `renovate.json` preset**: minor nits; not worth standalone plans.
