## Why this matters

Three database and cleanup improvements belong together so Room only bumps its schema version once (`26 -> 27`):
1. Missing SQLite indexes on `DownloadItem(videoId)`, `DownloadChapter(videoId)`, `DownloadSponsorBlockSegment(videoId)`, `SubscriptionsFeedItem(uploaded, uploaderUrl)`, and `LocalPlaylistItem(playlistId, videoId)` force full-table scans on FK cascade deletes, feed sorting/pruning, and playlist queries; `DownloadItem` also needs `sabrNextSegmentNumber` for accurate SABR download resume.
2. Dead LibreTube/Piped artifacts remain in the codebase: `CustomInstance` / `CustomInstanceDao` (0 callers), `ProxyHelper.unwrapUrl` (strips Piped `?host=...` params on every thumbnail URL even though Tubik uses NewPipeExtractor exclusively), ~5.8 MB of unused LibreTube `assets/` and `fastlane/.../phoneScreenshots/`, and `rootProject.name = "LibreTube"` in `settings.gradle.kts:26`.
3. `androidx.media:media:1.8.0` is used only for two redundant `MediaMetadataCompat` extras in `SetMetadata.kt`, and `logging-interceptor` is declared as `implementation` (release classpath) even though both callers are gated by `if (BuildConfig.DEBUG)`.

## Steps

### Step 1: Room schema v26 → v27 (indexes + `sabrNextSegmentNumber` + drop `CustomInstance`)

1. Add indexes:
   - `DownloadItem`: `indices = [Index(value = ["path"], unique = true), Index(value = ["videoId"])]` and add `@ColumnInfo(defaultValue = "NULL") var sabrNextSegmentNumber: Long? = null`.
   - `DownloadChapter`: `@Entity(tableName = "downloadChapters", indices = [Index(value = ["videoId"])])`.
   - `DownloadSponsorBlockSegment`: add `indices = [Index(value = ["videoId"])]`.
   - `SubscriptionsFeedItem`: `@Entity(tableName = "feedItem", indices = [Index(value = ["uploaded"]), Index(value = ["uploaderUrl"])])`.
   - `LocalPlaylistItem`: `@Entity(indices = [Index(value = ["playlistId"]), Index(value = ["playlistId", "videoId"])])`.
2. Delete `CustomInstance.kt` and `CustomInstanceDao.kt`, remove from `AppDatabase.kt` and `BackupFile.kt`.
3. In `DatabaseHolder.kt`, add `@DeleteTable(tableName = "customInstance") class MIGRATION_26_27 : AutoMigrationSpec`. In `AppDatabase.kt`, bump `version = 27` and add `AutoMigration(from = 26, to = 27, spec = DatabaseHolder.MIGRATION_26_27::class)`.

**Verify**: `./gradlew :app:kspDebugKotlin` → generates `app/schemas/com.github.libretube.db.AppDatabase/27.json` cleanly.

### Step 2: Remove `ProxyHelper`, stale LibreTube media, and `rootProject.name`

1. Delete `ProxyHelper.kt` and remove all `ProxyHelper.unwrapUrl(...)` calls in `StreamItem.kt`, `Playlist.kt`, `PlaylistFragment.kt`, and `SeriesRepository.kt`.
2. Delete `assets/` and `fastlane/metadata/android/en-US/images/phoneScreenshots/`.
3. Update `settings.gradle.kts:26` to `rootProject.name = "Tubik"`.

**Verify**: `grep -rn "ProxyHelper" app/src/` → no matches.

### Step 3: Drop `androidx.media` and scope `logging-interceptor` to `debugImplementation`

1. In `SetMetadata.kt`, remove `MediaMetadataCompat` import and the 4 `METADATA_KEY_TITLE` / `METADATA_KEY_ARTIST` `bundleOf` entries (lines 3, 22-23, 52-53).
2. Remove `androidx-media` from `app/build.gradle.kts:156` and `gradle/libs.versions.toml:39,95`.
3. Create `HttpLoggingConfigurator` in `app/src/debug/java/com/github/libretube/api/HttpLoggingConfigurator.kt` (adds `HttpLoggingInterceptor` with `BODY` or `BASIC` level) and a no-op `HttpLoggingConfigurator` in `app/src/release/java/com/github/libretube/api/HttpLoggingConfigurator.kt`. Replace `if (BuildConfig.DEBUG) { ... HttpLoggingInterceptor ... }` in `RetrofitInstance.kt` and `ImageHelper.kt` with `HttpLoggingConfigurator.configure(httpClient, ...)` and remove `okhttp3.logging.HttpLoggingInterceptor` imports from main sources.
4. Change `implementation(libs.logging.interceptor)` to `debugImplementation(libs.logging.interceptor)` in `app/build.gradle.kts:203`, rename `loggingInterceptor` version key to `okhttp` in `gradle/libs.versions.toml:22,78-79`, and replace `// TODO: exclude from release protobuf` at `app/build.gradle.kts:243` with `// Required in release builds for SABR streaming (SabrClient / SabrDownloadProvider).`.

**Verify**: `./tools/quality/gate.sh fast` → exit 0.
