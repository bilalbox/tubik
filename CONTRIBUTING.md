# Contributing

Ideas, translations, design, and code are welcome. Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).

Issues and pull requests belong in [this repository](https://github.com/bilalbox/tubik).

## What this app is for

Tubik is a YouTube client for a child's device: no trending, an Allowlist of subscribed channels, Music Removal, and a Parent PIN on Settings. A change should fit that. For a larger feature, open an issue before writing it.

## Translations

Translations are the `strings.xml` files under `app/src/main/res/`. English is `values/strings.xml`. Other languages are `values-<language>/strings.xml`.

## Code

Open the project in Android Studio and build it like any other Android app.

Pull request titles and commit messages use [conventional commit types](https://github.com/commitizen/conventional-commit-types/blob/master/index.json), for example `feat: explain the Allowlist on first launch`. Common types in this repo are `feat`, `fix`, `refactor`, `ci`, and `chore`.
